Vault

Your files, kept as one main file plus small change files.
How it works
  • Main holds all your files. You make it once.
  • Changes are small files, one per save. Each holds only what you changed.
  • Snapshot is an optional catch-up file. Main + the latest snapshot + later changes rebuild everything.
  • Combine rolls everything into a fresh main when you have too many pieces.
  • Keep every piece together. The tool reads the inside of each file, so a renamed file still works. "Vault files" below shows what each piece should be called.
